# PointClicker — AI Agent Guidelines & Instructions

This repository is maintained with strict quality, authorship, and engineering standards. All coding agents (including Claude, ChatGPT, Copilot, Antigravity, and other LLMs) working in this codebase must strictly adhere to the following rules:

---

## 1. Absolute Rule: No AI Self-Inclusion or Branding

- **Zero AI Credits or Self-Attribution**: NEVER include names, branding, signatures, or credits for AI models, assistants, or providers (such as Claude, Anthropic, OpenAI, Copilot, etc.) anywhere in this project.
- **Git Commits**: NEVER append `Co-Authored-By:` lines referencing AI entities (e.g. `Co-Authored-By: Claude...`). Commits must contain clean, descriptive commit messages authored strictly by the human contributor (`Khalil Ullah Naul`).
- **Source Code & Comments**: Do NOT mention "generated by AI", "Claude helped write this", or similar notes in docstrings, comments, or variable names.
- **User Interface & Documentation**: The application's UI, About screen, landing page, README, license, and documentation must only reference the project name (`PointClicker`) and human maintainer.

---

## 2. Code Quality & Architectural Principles

- **Standard Library & Native APIs First**: Reach for Python standard library modules or native OS capabilities before introducing third-party packages. Avoid unnecessary dependencies or over-engineered abstractions.
- **Single Source of Truth for Versioning**: Application version is defined exclusively in `src/pointclicker/__init__.py` as `__version__ = "X.Y.Z"`. Never hardcode version strings across other files.
- **Cross-Platform Robustness**:
  - **Windows**: Win32 SendInput / PostMessage, Windows 11 Fluent UI, Inno Setup packaging.
  - **Linux**: X11 (XTest, XSendEvent, XGrabKey) and Wayland (RemoteDesktop portal, uinput, screenshot portal).
- **Responsive Architecture**:
  - The UI runs on the main Qt thread; the click engine runs on a dedicated high-precision scheduler thread.
  - Never execute blocking I/O, heavy computation, or click sleep loops on the Qt main thread.
- **Verification**: Run `ruff check .` and `pytest` before finalizing changes. Ensure all tests and smoke diagnostics pass (`python build.py --smoke`).
